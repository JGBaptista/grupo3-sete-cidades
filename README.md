# Grupo 3 · Sete Cidades — site

Single-page static site: P0–P5 local study + Ex.2 AI imagery (Joao / Lia / Belisa).
Dark Halcyon-style theme with light/dark toggle. No build step, no dependencies.

```
grupo3-site/
  index.html        all content + structure
  assets/site.css   all styling
  assets/img/       all photos (10 site + 15 Ex.2)
```

## Publish on GitHub Pages

1. Create a new repository on GitHub (any name, public).
2. Upload this folder's contents so the repo root contains `index.html` and `assets/`
   (web upload works, or: `git add .`, `git commit`, `git push`).
3. Repo Settings → Pages → Build and deployment → Deploy from a branch →
   branch `main`, folder `/ (root)` → Save.
4. Open the `https://<user>.github.io/<repo>/` link Pages shows (takes ~1 min).

Nothing else needed — deep links like `#p3` and `#ex2` work as-is.
